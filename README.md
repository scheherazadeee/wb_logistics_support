# Wildberries Logistics Decision Support System

This project implements a seller-centric decision support system for inventory distribution across Wildberries warehouses under demand uncertainty.

## Project Structure
- ingestion: data retrieval from marketplace reports
- preprocessing: data cleaning and aggregation
- demand_model: probabilistic demand estimation
- cost_model: logistics and storage cost modeling
- simulation: scenario-based simulation
- optimization: selection of optimal inventory allocation
